Yovarela Studio V4.4

Base: V4.3.
Cambios:
- Catálogo permite agregar productos nuevos.
- Cada producto nuevo se asigna a una categoría y guarda parámetros de cálculo según categoría.
- Se puede guardar descripción, material/base y foto.
- Los productos nuevos quedan disponibles directamente en el cotizador.
- Cotizaciones: guardar localmente y enviar por correo mediante el cliente de correo del equipo.
- WhatsApp: exportación del catálogo mediante mensaje preparado.

Uso: ejecutar servidor.py y abrir index.html desde el servidor local.
